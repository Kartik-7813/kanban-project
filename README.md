# KanbanDesk

A simple web-based Kanban dashboard for organizing and tracking project activities through three stages: **To Do**, **In Progress**, and **Done**.

## Features

- Add tasks with a title and description.
- Move tasks between the three columns using drag and drop.
- Double-click a task to edit its title or description.
- Delete tasks when they are no longer needed.
- See the task count for each column.
- Automatically save tasks in your browser using `localStorage`, so they remain available when you reopen the page in the same browser.

## Getting started

This project uses plain HTML, CSS, and JavaScript. No installation, build step, or additional dependencies are required.

1. Clone or download this repository.
2. Open `index.html` in a modern web browser.
3. Select **Add New Task** to create a task, then drag it to another column as its status changes.

> Tasks are stored locally in the browser and are not synced between devices or browsers.

## Project files

- `index.html` — dashboard layout and task columns.
- `style.css` — page styling and layout.
- `script.js` — task creation, editing, deletion, drag and drop, and local storage.
